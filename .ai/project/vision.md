# Project Vision

## One-sentence vision

MeetXT is a local-first Ruby CLI for developers and technical professionals that turns meeting audio into readable, timestamped Markdown transcripts.

## Problem

Meeting recordings are difficult to search, review, summarize, or mine for actions without a transcript. Existing solutions often require platform integrations, bots, accounts, or broader hosted products.

## Desired outcome

One command reliably turns a local recording into a human-readable transcript beside it, while keeping the external transcription provider replaceable.

## Non-goals

The first version is not a recorder, GUI/web app, meeting bot, platform/calendar integration, diarization tool, summarizer, action extractor, cloud store, or account system.
